# Generated Knowledge client boundary

`Generated/KnowledgeApiClient.g.cs` is machine-generated by NSwag from `docs/contracts/knowledge-v0.openapi.yaml` and checked in — do not hand-edit it. `HttpKnowledgeService` is the only file allowed to reference the generated `Generated.*` types; it implements `TenderHack.Application.Knowledge.IKnowledgeService` and is the single funnel that turns a failed call into `KnowledgeFailureException` (knowledge-v0.md §3).

## Regenerating

After `docs/contracts/knowledge-v0.openapi.yaml` changes:

```bash
dotnet tool install --global NSwag.ConsoleCore --version 14.7.1   # once
nswag run src/TenderHack.Infrastructure/KnowledgeClient/nswag.json
```

Then update `HttpKnowledgeService` for any shape change and rebuild.
